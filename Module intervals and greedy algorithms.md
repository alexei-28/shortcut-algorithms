### Merge Intervals
Паттерн: Слияние перекрывающихся интервалов 
Связь с темой: 
Классическая задача слияния интервалов Задача встречается на собеседованиях в Яндекс

Дан массив интервалов intervals, где intervals[i] = [start_i, end_i]. Слейте все перекрывающиеся интервалы и верните массив неперекрывающихся интервалов.

Источник: LeetCode 56

Пример:
```code
Вход: intervals = [[1,3],[2,6],[8,10],[15,18]]
Выход: [[1,6],[8,10],[15,18]]

Вход: intervals = [[1,4],[4,5]]

Выход: [[1,5]]
```

Требования:

Временная сложность: O(n log n)

Пространственная сложность: O(n)

Подсказка:

Сначала отсортируйте интервалы по началу. Затем проходите по отсортированному списку и объединяйте перекрывающиеся интервалы. 
Текущий интервал пересекается с последним добавленным, если current.start <= last.end.
