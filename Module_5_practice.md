### Задание 1: Binary Search [Easy]
Паттерн: Точный поиск элемента Пример из лекции: Классический бинарный поиск

Дан отсортированный массив целых чисел nums и целевое значение target. Верните индекс target, если он найден. Если нет, верните -1.

Источник: https://leetcode.com/problems/binary-search/

Пример:

Вход: nums = [-1,0,3,5,9,12], target = 9
Выход: 4

Вход: nums = [-1,0,3,5,9,12], target = 2

Выход: -1
Требования:

Временная сложность: O(log n)

Пространственная сложность: O(1)


Подсказка:

Используйте стандартный бинарный поиск с двумя указателями left и right. 
Вычисляйте mid как середину между left и right (целочисленное деление; в JavaScript — Math.floor) и сравнивайте nums[mid] с target.


## Задание 2: Search Insert Position [Easy]
Паттерн: Поиск места вставки

Дан отсортированный массив целых чисел и целевое значение. Верните индекс, если цель найдена. Если нет, верните индекс, куда цель должна быть вставлена по порядку.

Источник: https://leetcode.com/problems/search-insert-position/description/

Пример:

Вход: nums = [1,3,5,6], target = 5
Выход: 2

Вход: nums = [1,3,5,6], target = 2

Выход: 1

Вход: nums = [1,3,5,6], target = 7

Выход: 4

Требования:

Временная сложность: O(log n)

Пространственная сложность: O(1)

Подсказка

Используйте стандартный бинарный поиск. Если элемент не найден, переменная left будет указывать на правильное место для вставки.

### Задание 3: Sqrt(x) [Easy]
Паттерн: Бинарный поиск по ответу

Дано неотрицательное целое число x. Вычислите и верните квадратный корень из x, округленный вниз до ближайшего целого числа.

Источник: https://leetcode.com/problems/sqrtx/

Пример:
Вход: x = 4
Выход: 2

Вход: x = 8
Выход: 2 (квадратный корень из 8 равен 2.828..., округляем вниз до 2)
Требования:

Временная сложность: O(log n)
Пространственная сложность: O(1)

Не используйте встроенные функции sqrt() или операторы возведения в степень

Подсказка:

Используйте бинарный поиск по ответу в диапазоне от 0 до x. 
Для каждого mid проверяйте: mid * mid <= x. Если да, возможно есть больший корень (ищите правее). Иначе ищите левее.


### Задание 4: Guess Number Higher or Lower [Easy]
Паттерн: Точный поиск элемента

Мы играем в игру "Угадай число". Игра работает так: я загадываю число от 1 до n. 
Вам нужно угадать какое число я загадал. Каждый раз, когда вы делаете неправильную догадку, 
я скажу вам, загаданное число больше или меньше вашей догадки.

Источник: https://leetcode.com/problems/guess-number-higher-or-lower/

Пример:

Вход: n = 10, pick = 6
Выход: 6

Требования:

Временная сложность: O(log n)
Пространственная сложность: O(1)

Подсказка:
Используйте бинарный поиск. Вызывайте guess(mid): 
если результат 0 — вы нашли число; если -1 — ищите в левой половине; если 1 — ищите в правой половине.


### Задание 5: Find First and Last Position of Element [Medium]
Паттерн: Поиск первого/последнего вхождения

Дан отсортированный массив целых чисел nums и целевое значение target. Найдите начальную и конечную позиции target в массиве.
Если target не найден, верните [-1, -1].

Источник: https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/

Пример:
Вход: nums = [5,7,7,8,8,10], target = 8
Выход: [3,4]

Вход: nums = [5,7,7,8,8,10], target = 6
Выход: [-1,-1]

Требования:

Временная сложность: O(log n)
Пространственная сложность: O(1)

Подсказка
Используйте два бинарных поиска: 
один для поиска первого вхождения (при nums[mid] == target продолжайте искать левее), 
другой для последнего вхождения (при nums[mid] == target продолжайте искать правее).

### Задание 6: Search in Rotated Sorted Array [Medium]
Паттерн: Работа с отсортированным массивом после циклического сдвига 
Связь с темой: Поиск в отсортированном массиве после циклического сдвига

Дан отсортированный массив, к которому применили циклический сдвиг на неизвестное число позиций 
(в англоязычной формулировке — rotated: несколько элементов «перекатились» с конца в начало).
Найдите целевой элемент. Если элемент не найден, верните -1.

Источник: https://leetcode.com/problems/search-in-rotated-sorted-array/

Пример:

Вход: nums = [4,5,6,7,0,1,2], target = 0
Выход: 4

Вход: nums = [4,5,6,7,0,1,2], target = 3
Выход: -1

Требования:

Временная сложность: O(log n)

Пространственная сложность: O(1)

Подсказка
Используйте модифицированный бинарный поиск. Определите, какая половина массива отсортирована. 
Затем проверьте, находится ли target в этой половине. Если да, ищите там, иначе в другой половине.

### Задание 8: Koko Eating Bananas [Medium]
Паттерн: Бинарный поиск по ответу

Коко любит есть бананы. Есть n куч бананов, в i-й куче piles[i] бананов. Охранники ушли и вернутся через h часов. 
Коко может решить, с какой скоростью k (бананов в час) она будет есть бананы.

Каждый час Коко выбирает одну кучу и съедает из неё до k бананов. Если в куче меньше k бананов, 
она съедает всю кучу и в этот час больше не ест — к следующей куче переходит только в следующий час. 
Из-за этого куча piles[i] всегда занимает ceil(piles[i] / k) часов: остаток часа простаивает, 
и «недоеденную» скорость нельзя перенести на другую кучу. 
Поэтому нельзя просто сложить все бананы и поделить на h — часы считаются по кучам отдельно.

Верните минимальную скорость k, при которой Коко успеет съесть все бананы за h часов.

Источник: https://leetcode.com/problems/koko-eating-bananas/description/

Пример:

Вход: piles = [3,6,7,11], h = 8
Выход: 4

Вход: piles = [30,11,23,4,20], h = 5
Выход: 30

Требования:

Временная сложность: O(n log m), где n — количество куч, m — максимальное количество бананов в куче
Пространственная сложность: O(1)

Подсказка
Используйте бинарный поиск по ответу. Диапазон скорости: от 1 до max(piles). Для каждой скорости 
k проверяйте: успеет ли Коко съесть все бананы за h часов? Если успевает, пробуйте меньшую скорость, иначе нужна большая.
